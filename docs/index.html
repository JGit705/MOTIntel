MOTIntel
Real MOT data. Smarter decisions. View on GitHub

Should you buy that used car? 42.7 million MOT tests have an opinion.

Pick a make, model and age. MOTIntel shows how often that car failed its MOT in 2025 compared with every car the same age, what goes wrong with it, whether mileage matters, how it stacks up against the cars you're weighing it against, and what to look at when you go and see one. An LLM interprets the findings, and every answer is checked against the data before anyone sees it.

View the code Run it yourself Three findings

About the data: every figure comes from the DVSA's anonymised MOT results for tests carried out between 1 January and 30 December 2025. It is one year of tests, not a car's full history. This page is a showcase: the app itself runs on your own machine.

What the data says

Three findings from 2025

Measured across every first MOT test in the year, after retests and aborted tests were removed.

1Old cars fail less, because the bad ones are gone.

The failure rate climbs from 11.0% at 0–3 years old to a peak of 42.7% at 18–21 years, then falls to 33.3% by 27–30. Old cars don't get better. The neglected ones were scrapped, so the cars still taking an MOT at 25 are the looked-after minority. That is survivorship bias, measured directly.

  • 0–3 yrs11.01%1,475,242 tests
  • 6–9 yrs20.91%7,465,670 tests
  • 12–15 yrs37.53%4,874,900 tests
  • 18–21 yrs42.72%1,858,569 tests · the peak
  • 27–30 yrs33.33%121,698 tests

Bars run from 0% to 50%.

2Machine learning barely beat a simple average, so the app doesn't use it.

Trained on January to September 2025 and tested on October to December 2025, XGBoost beat a plain make/model/age average by 0.017 AUC, and the average was better calibrated. The page shows the observed rate, not a prediction.

Like for like

Compare cars at the same age

Up to three more cars, always at the same age, because a 4-year-old car against a 12-year-old one mostly measures the eight years between them. One search box covers all 5,998 cars, and the view lives in the URL, so any comparison can be shared.

How it works

From 8.5 GB of ZIPs to one page of answers

The heavy work happens once, offline. The app only ever reads 1.9 MB of pre-calculated results.

  1. Ingest

    42.7 million tests and 92.5 million defect records loaded into DuckDB as they are, in about 49 seconds.

    ingest.py

  2. Clean

    One row per test. Every filter is counted and reported, and the quirks that contradict DVSA's own guide are handled.

    transform.py

  3. Model comparison

    A plain average against logistic regression and XGBoost, split by date so no car leaks across. Kept as evaluation only.

    model.py

  4. Export

    Everything the page can show, pre-calculated into 1.9 MB of Parquet. Groups under 30 tests are dropped.

    export.py

  5. LLM enrichment

    515 terse DVSA defect fragments turned into plain English, validated by rules and reviewed by a person.

    enrich.py

  6. Findings

    One profile per car, read by both the page and the AI, including a rank with mileage levelled out.

    serving.py

  7. The page

    A Streamlit app laid out as a buyer's five questions, from "Is it reliable?" to "What should I check?"

    motintel_app.py

  8. AI interpretation

    Gemini sees only the car's figures, returns structured JSON, and is checked before anything is shown.

    grounding.py

AI, checked

Measured, not assumed

An answer is rejected before it is saved or shown if it:

  • contains a figure that isn't in the data it was given;
  • mentions anything outside the data, such as a price, a recall or advice to buy or avoid;
  • describes a car with too few tests instead of declining;
  • declines a well-covered car, because a model that refused everything would otherwise pass.
Figures checked against their source data199 across 18 answers

Run it yourself

The app runs on your machine

You'll need Python 3.11 or newer and around 25 GB of free disk space. None of the data is in the repository: download the three 2025 files from the DVSA's anonymised MOT data page and follow the full setup steps. 

git clone https://github.com/JGit705/MOTIntel.git
cd MOTIntel
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt

./.venv/bin/python -m motintel.run_pipeline
./.venv/bin/python -m motintel.export
./.venv/bin/streamlit run motintel_app.py

Read with care

What an MOT failure rate is not

It isn't a reliability score. The MOT checks safety and emissions once a year, can't see anything repaired in between, and reflects how a car was looked after as much as how it was built. This project covers 2025 only, so it can't show how a model changed from year to year. Fuel type is unreliable for older hybrids, and the data has no repair costs.
